# Starlove Mod
## 概要
このmodは、（恐らく）全てのエンティティを削除するアイテムを追加します。
## 削除可能なエンティティ
* バニラのエンティティ
* Pig2(2.6.0)
* フメツウィザー
* Trial Monolith, Invader Monolith, Tesseract Beast
* UOM
* Madness Entities
* Super Steve
* Omni-Mobsで追加されるMetapotent Flashfur以外のエンティティ
* 
## 仕組み
ワールドのentitiesフォルダ内のファイルを全て削除します。それだけです。
独自の保存方法を実装しているエンティティは削除できません。
